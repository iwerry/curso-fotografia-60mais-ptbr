## 📖 Sobre o Curso

O **Curso de Fotografia 60+** é um programa educacional completo voltado para pessoas de todas as idades, com foco especial em maiores de 60 anos, que desejam aprender ou aprimorar suas habilidades fotográficas.

O curso **"Alfabetização do Olhar"** foi criado pelo **Prof. Daniel Rodrigues** com o objetivo de democratizar o acesso ao conhecimento fotográfico, mostrando que a fotografia é uma arte acessível a todos, independente da idade ou do equipamento utilizado.

### 🎯 Objetivos

- Despertar o olhar fotográfico em cada aluno
- Ensinar fundamentos da composição, luz e enquadramento
- Desenvolver a sensibilidade artística
- Capacitar os alunos a criar um portfólio pessoal
- Promover a inclusão digital e artística de pessoas 60+

### 👥 Público-Alvo

- Pessoas maiores de 60 anos que desejam um novo hobby criativo
- Iniciantes de qualquer idade que querem aprender fotografia
- Aposentados buscando atividade intelectual e artística
- Qualquer pessoa interessada em desenvolver o olhar fotográfico

> 💡 **Não é necessário ter câmera profissional** — celulares são perfeitamente adequados para o curso!

## 📚 Conteúdo Programático

O curso é dividido em **8 semanas** de aprendizado progressivo:

| Semana | Tema | Descrição |
|--------|------|-----------|
| 1 | 👁️ O Despertar do Olhar | Aprenda a observar o mundo com novos olhos |
| 2 | 📐 Composição e Enquadramento | Domine as regras da composição fotográfica |
| 3 | 💡 Luz e Sombra | Entenda como a luz transforma a fotografia |
| 4 | ✨ A Maestria da Luz e Sombra | Técnicas avançadas de iluminação |
| 5 | 👤 Fotografia de Pessoas | Capture a essência em retratos |
| 6 | 🎨 Fotografando Objetos | Still life e fotografia criativa |
| 7 | 🖥️ Edição de Fotografia | Pós-produção e tratamento de imagens |
| 8 | 📁 Portfólio | Monte e apresente seu trabalho ao mundo |

### Material por Semana

Cada semana inclui:
- 📖 **Ebook** — Material teórico em PDF
- 🎬 **Videoaula** — Aula prática em vídeo
- 📝 **Exercícios** — Atividades práticas guiadas

## 🚀 Como Executar Localmente

### Pré-requisitos
- Node.js 18+
- npm ou yarn

### Instalação

```bash
# Clone o repositório
git clone https://github.com/iwerry/curso-fotografia-60mais-ptbr.git

# Entre no diretório
cd curso-fotografia-60mais-ptbr

# Instale as dependências
npm install

# Execute em modo desenvolvimento
npm run dev

# Para build de produção
npm run build
```

O site estará disponível em `localhost`
